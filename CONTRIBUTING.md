# Contributing

InfrastructureIntent is establishing its contributor-rights model before accepting external code contributions.

Until that contributor agreement is finalized, external pull requests should not be submitted for incorporation into InfrastructureIntent-owned repositories. Issues and discussions may be used for feedback, design questions, bug reports, and proposed improvements.

Repository maintainers may still use this template for InfrastructureIntent-owned work.

When external contributions open, contributor requirements will be defined canonically in `InfrastructureIntent/documentation` and reflected here.
